# Emergency Center

Emergency Center is a restored and simplified version of a full-stack bootcamp project originally developed using Node.js, Express, Handlebars, Sequelize, and MySQL.

This archived version was redesigned into a lightweight static website using HTML, CSS, and JavaScript to improve long-term maintainability, portability, and GitHub Pages compatibility.

The project preserves the original concept, visual identity, and user experience while removing dependency on backend services and external infrastructure.
